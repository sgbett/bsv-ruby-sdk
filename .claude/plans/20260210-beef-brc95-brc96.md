# BEEF (BRC-95/BRC-96) — Task #17

## Context

Issue #17, sub-task of HLR #11. Implements the Background Evaluation Extended Format for compact SPV-aware transaction serialisation. BEEF bundles transactions with their merkle proofs (BUMPs) so recipients can verify inclusion without trusting intermediaries.

## Implementation

### Modifications to Existing Classes

**Transaction** — add `attr_accessor :merkle_path` (MerklePath or nil). Not part of binary tx serialisation; it's metadata carried alongside the transaction.

**TransactionInput** — add `attr_accessor :source_transaction` (Transaction or nil). Used during BEEF deserialisation to wire up ancestor references.

### Constants

```ruby
BEEF_V1     = 0x0100BEEF  # 4022206465 — BRC-62 legacy
BEEF_V2     = 0x0200BEEF  # 4022206466 — BRC-96
ATOMIC_BEEF = 0x01010101  # BRC-95
```

Written/read as 4-byte little-endian uint32.

### Data Structures

**`BeefTx`** — nested value object tracking per-transaction BEEF metadata:

```ruby
class BeefTx
  attr_reader :format, :transaction, :known_txid, :bump_index

  # format: :raw_tx (0), :raw_tx_and_bump_index (1), :txid_only (2)
end
```

**`Beef`** — the main container:

```ruby
class Beef
  attr_reader :version, :bumps, :transactions

  # bumps: Array of MerklePath
  # transactions: ordered Array of BeefTx (dependency order — ancestors first)
end
```

### Binary Format

#### BEEF V2 (BRC-96)

```
[Version: 4 bytes LE]           0x0200BEEF
[nBUMPs: VarInt]
[BUMP data × nBUMPs]            each is MerklePath.to_binary
[nTransactions: VarInt]
[Transaction entries × nTxs]    in dependency order (ancestors first)
```

Each transaction entry:
```
[DataFormat: 1 byte]
  0x00 = RawTx           → [tx bytes]
  0x01 = RawTxAndBumpIndex → [VarInt bump_index] + [tx bytes]
  0x02 = TxIDOnly        → [32-byte txid]
```

#### BEEF V1 (BRC-62) — read-only

```
[Version: 4 bytes LE]           0x0100BEEF
[nBUMPs: VarInt]
[BUMP data × nBUMPs]
[nTransactions: VarInt]
[Transaction entries × nTxs]
```

Each V1 transaction entry:
```
[tx bytes]
[hasBump: 1 byte]              0x00 = no bump, non-zero = has bump
if hasBump:
  [VarInt bump_index]
```

#### Atomic BEEF (BRC-95)

```
[0x01010101: 4 bytes LE]
[Subject TXID: 32 bytes]        internal byte order (same as tx serialisation)
[BEEF V2 data]                  standard V2 format
```

### Methods

#### `Beef.from_binary(data)` → `Beef`

1. Read 4-byte version (LE uint32)
2. If ATOMIC_BEEF: read 32-byte subject txid, then parse remainder as V2
3. Read nBUMPs (VarInt), then each BUMP via `MerklePath.from_binary`
4. Read nTransactions (VarInt)
5. For each transaction:
   - Read format byte
   - **TxIDOnly (2):** read 32-byte txid
   - **RawTxAndBumpIndex (1):** read VarInt bump_index, then full tx via `Transaction.from_binary`; attach `bumps[bump_index]` as `tx.merkle_path`
   - **RawTx (0):** read full tx via `Transaction.from_binary`
6. Wire source transactions: for each parsed tx, check each input's `prev_tx_id` against previously-parsed transactions; set `input.source_transaction` if found
7. For Atomic BEEF: store subject_txid, find and return the subject transaction

#### `Beef.from_hex(hex)` → `Beef`

#### `#to_binary` → `String`

1. Write BEEF_V2 version (4 bytes LE)
2. Collect unique BUMPs from transactions that have merkle_paths; build bump index map
3. Write nBUMPs (VarInt) + each bump's `to_binary`
4. Write nTransactions (VarInt)
5. For each transaction (already in dependency order):
   - **TxIDOnly:** write `\x02` + 32-byte txid
   - **RawTxAndBumpIndex:** write `\x01` + VarInt(bump_index) + tx.to_binary
   - **RawTx:** write `\x00` + tx.to_binary

#### `#to_hex` → `String`

#### `#to_atomic_binary(subject_txid)` → `String`

Write ATOMIC_BEEF prefix + subject txid + V2 payload.

#### `#find_transaction(txid)` → `Transaction` or `nil`

Look up by txid (32-byte binary). Scans transactions array.

### Transaction.from_binary offset support

Currently `Transaction.from_binary(data)` doesn't return bytes consumed. For BEEF, we read multiple transactions sequentially, so we need to know how many bytes each consumed. Two options:

**Option A:** Modify `from_binary` to return `[tx, bytes_consumed]` (breaking change).
**Option B:** Add `from_binary_with_offset(data, offset)` that returns `[tx, consumed]`.

**Recommendation: Option B** — non-breaking. The existing `from_binary(data)` stays unchanged. The new method is used internally by Beef.

- Transactions with merkle_paths have them attached
- Source transaction wiring: child tx inputs reference parent txs

**Empty BEEF:**
- V2 empty: 0 bumps, 0 transactions
- V1 empty: 0 bumps, 0 transactions

- Construct Beef → to_atomic_binary(txid) → parse back → find transaction by txid

- After parsing V2 BEEF, child transaction inputs have source_transaction set
- source_transaction.txid matches input.prev_tx_id
