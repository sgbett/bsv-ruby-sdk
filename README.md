# BSV Ruby SDK

Ruby implementation of the BSV Blockchain SDK.

> **Status:** Early development — infrastructure only, no BSV functionality yet.

## Installation

Add to your Gemfile:

```ruby
gem "bsv-sdk"
```

Or install directly:

```bash
gem install bsv-sdk
```

## Development

```bash
git clone https://github.com/sgbett/bsv-ruby-sdk.git
cd bsv-ruby-sdk
bundle install
bundle exec rake        # run specs
bundle exec rubocop     # run linter
```

Requires Ruby >= 2.7.
